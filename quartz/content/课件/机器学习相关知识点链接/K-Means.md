# K-Means

> [!abstract] 一句话概括
> K-Means 是一种**无监督聚类算法**：在没有类别标签的情况下，把相似的样本划分到同一组，并用每组的均值作为聚类中心。

## 1. 基本思想

给定 $n$ 个样本，K-Means 预先指定聚类数 $K$，将样本划分为 $K$ 个簇。算法希望同一簇内的样本尽量接近，不同簇尽量分开。

它最小化簇内平方和（Within-Cluster Sum of Squares, WCSS）：

$$
\min \sum_{k=1}^{K}\sum_{\mathbf{x}_i\in C_k}
\left\|\mathbf{x}_i-\boldsymbol{\mu}_k\right\|^2,
$$

其中：

- $C_k$ 是第 $k$ 个簇；
- $\boldsymbol{\mu}_k$ 是该簇所有样本的均值，即聚类中心；
- 距离通常采用欧氏距离。

## 2. 算法步骤

1. 设定聚类数量 $K$；
2. 随机选择 $K$ 个初始聚类中心；
3. 把每个样本分配给距离最近的中心；
4. 对每个簇重新计算均值，得到新的中心；
5. 重复步骤 3～4，直到样本分组基本不变或目标函数不再明显下降。

> [!example] 直观例子
> 若一组顾客具有“年收入”和“消费金额”两个特征，设置 $K=3$ 后，K-Means 可能将顾客分成低消费、中等消费和高消费三个群体。但这些名称不是算法提供的，需要研究者观察聚类中心后自行解释。

## 3. 使用时要注意

- **必须预先选择 $K$**：可结合肘部法、轮廓系数和业务知识判断；肘部法寻找 WCSS 下降开始明显变缓的位置。
- **需要特征标准化**：量纲较大的变量会主导欧氏距离，通常应先做标准化。
- **结果受初始中心影响**：不同初值可能得到不同结果，应进行多次随机初始化，并选择 WCSS 较小的结果。
- **对异常值敏感**：极端值会拉动均值和聚类中心。
- **适合近似球状、尺度相近的簇**：面对弯曲形状、密度差异明显或大小悬殊的簇时，效果可能较差。
- **聚类编号没有顺序和固定含义**：第 1 簇不一定“优于”第 2 簇，编号也可能随初始化改变。

## 4. 优缺点

| 优点 | 局限 |
|---|---|
| 原理直观，容易实现 | 需要提前指定 $K$ |
| 在中大型数值型数据上通常较快 | 对初始中心和异常值敏感 |
| 聚类中心便于描述每组的典型特征 | 依赖距离和特征尺度 |
| 适合作为聚类分析的基线方法 | 不擅长发现复杂形状的簇 |

## 5. K-Means 与 KNN 的区别

K-Means 和 [[分类器#2.3 K 最近邻（K-Nearest Neighbors, KNN）|KNN]] 名称相似，但用途不同：

| 对比项 | K-Means | KNN |
|---|---|---|
| 学习类型 | 无监督学习 | 监督学习 |
| 是否需要标签 | 不需要 | 需要已标记样本 |
| 主要任务 | 聚类、探索数据结构 | 分类或回归预测 |
| $K$ 的含义 | 聚类的数量 | 参与投票或平均的邻居数量 |
| 核心操作 | 反复更新聚类中心 | 查找新样本最近的训练样本 |

因此，K-Means 通常不属于“分类器”：**分类**预测已有类别，**聚类**则从数据中探索可能存在的群组。

## 6. R 中的简单示例

```r
# 使用 iris 的 4 个数值特征，并先标准化
x <- scale(iris[, 1:4])

set.seed(123)
fit <- kmeans(x, centers = 3, nstart = 25)

fit$centers       # 各簇中心
fit$size          # 各簇样本数
fit$tot.withinss  # 总簇内平方和，越小表示簇内越紧密

# iris 有真实物种标签，仅用于事后比较，不参与 K-Means 训练
table(cluster = fit$cluster, species = iris$Species)
```

其中，`centers = 3` 指定三个簇；`nstart = 25` 表示从 25 组不同的初始中心出发，保留目标函数较好的结果。

## 7. 核心总结

- K-Means 是无监督聚类算法，不需要预先提供类别标签。
- 它通过“分配样本—更新均值”反复迭代，使同一簇内的样本更加接近。
- 使用前应重视标准化、$K$ 值选择、多次初始化和异常值检查。
- K-Means 中的 $K$ 是簇数；KNN 中的 $K$ 是邻居数，两者不是同一种算法。
