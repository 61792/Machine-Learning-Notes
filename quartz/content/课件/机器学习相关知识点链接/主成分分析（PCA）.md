# 主成分分析（PCA）

> [!abstract] 一句话理解
> **PCA 把一组可能相关的原始变量，重新表示为少数几个[[彼此正交]]、按解释方差由大到小排列的线性组合。** 这些新变量叫作**主成分**（Principal Components, PCs）。

## 1. PCA 解决什么问题

当数据有 $p$ 个数值特征时，PCA 试图用较少的 $k$ 个主成分（$k<p$）保留数据中的主要变异。

常见用途：

- **降维与压缩**：用少数主成分代替大量原始变量；
- **二维或三维可视化**：用 PC1、PC2（必要时再加 PC3）观察样本结构；
- **去除冗余与共线性**：主成分两两不相关，可作为后续回归或分类模型的输入；
- **一定程度的去噪**：舍弃解释方差很小的方向；
- **数据探索**：通过得分和载荷观察样本差异与变量关系。

> [!important] PCA 的定位
> PCA 是一种**无监督、线性**的降维方法。计算主成分时只使用 $X$，不使用响应变量 $Y$，因此“解释 $X$ 的方差最多”不一定等于“预测 $Y$ 最好”。

## 2. 直观理解：旋转坐标轴

把二维数据想象成一团倾斜的椭圆形点云：

1. **PC1** 沿点云最“长”的方向，投影后的样本方差最大；
2. **PC2** 与 PC1 垂直，并在剩余方向中使方差最大；
3. 更高维时继续寻找与已有方向都正交的新方向。

因此，PCA 主要是在做两件事：

1. 把坐标轴旋转到数据变异最明显的方向；
2. 只保留前几个方向，实现降维。

> [!note] “方差大”为什么被视为信息多
> 如果样本在某个方向上的取值几乎相同，该方向很难区分样本；变化越明显，通常包含的结构信息越多。但这只是 PCA 的无监督准则，并不保证大方差方向一定与研究目标最相关。

## 3. 数学定义

### 3.1 数据中心化

设数据矩阵为 $X\in\mathbb{R}^{n\times p}$，$n$ 是样本数，$p$ 是变量数。先对每列减去样本均值：

$$
\tilde{x}_{ij}=x_{ij}-\bar{x}_j.
$$

若还需要标准化，则进一步除以该变量的样本标准差 $s_j$：

$$
x_{ij}^{*}=\frac{x_{ij}-\bar{x}_j}{s_j}.
$$

下文用 $X_c$ 表示经过中心化，或经过中心化与标准化后的矩阵。

### 3.2 第一主成分

第一主成分得分是原始变量的线性组合：

$$
z_{i1}=\phi_{11}x_{i1}^{c}+\phi_{21}x_{i2}^{c}+\cdots+\phi_{p1}x_{ip}^{c}.
$$

向量

$$
\boldsymbol\phi_1=(\phi_{11},\phi_{21},\ldots,\phi_{p1})^T
$$

称为第一主成分的**载荷向量**（loading vector）。PCA 求解：

$$
\max_{\boldsymbol\phi_1}\operatorname{Var}(X_c\boldsymbol\phi_1),
\qquad
\text{s.t. }\|\boldsymbol\phi_1\|_2=1.
$$

单位长度约束防止通过无限放大系数来人为增大方差。

### 3.3 后续主成分

第 $m$ 个主成分仍要最大化投影方差，但还必须与此前的载荷方向正交：

$$
\max_{\boldsymbol\phi_m}\operatorname{Var}(X_c\boldsymbol\phi_m),
\quad
\text{s.t. }\|\boldsymbol\phi_m\|_2=1,
\quad
\boldsymbol\phi_m^T\boldsymbol\phi_\ell=0\ (\ell<m).
$$

结果是不同主成分得分之间不相关：

$$
\operatorname{Cov}(Z_m,Z_\ell)=0,\qquad m\ne\ell.
$$

> [!warning] 正交、不相关与独立不是一回事
> 载荷向量“正交”是几何关系；主成分得分“不相关”是二阶统计关系。除某些特殊分布（如联合正态）外，不相关不能直接推出统计独立。

### 3.4 特征值分解与矩阵表达

令样本协方差矩阵为

$$
S=\frac{1}{n-1}X_c^TX_c.
$$

对 $S$ 做特征值分解：

$$
S=V\Lambda V^T,
$$

其中：

- $V=(\boldsymbol\phi_1,\ldots,\boldsymbol\phi_p)$：各主成分的载荷向量；
- $\Lambda=\operatorname{diag}(\lambda_1,\ldots,\lambda_p)$；
- $\lambda_1\ge\lambda_2\ge\cdots\ge\lambda_p\ge0$：各主成分的方差。

所有主成分的**得分矩阵**为：

$$
Z=X_cV.
$$

中心化后最多有 $\min(n-1,p)$ 个方差非零的主成分；当变量之间存在精确线性关系时，实际非零主成分数还会更少。

若只保留前 $k$ 个主成分，则：

$$
Z_k=X_cV_k,
\qquad
\hat X_c=Z_kV_k^T.
$$

$\hat X_c$ 是用 $k$ 个主成分对中心化数据的低秩重构。保留的主成分越多，重构误差越小。

> [!tip] 另一种理解
> PCA 的前 $k$ 个主成分，不仅使投影后的方差最大，也在平方误差意义下给出对数据矩阵的最佳秩-$k$ 线性近似。

## 4. 解释方差与主成分数量

第 $m$ 个主成分的方差等于对应特征值 $\lambda_m$。其**方差解释比例**（Proportion of Variance Explained, PVE）为：

$$
\operatorname{PVE}_m=\frac{\lambda_m}{\sum_{j=1}^{p}\lambda_j}.
$$

前 $k$ 个主成分的**累计方差解释比例**为：

$$
\operatorname{CPVE}_k
=\sum_{m=1}^{k}\operatorname{PVE}_m.
$$

选择 $k$ 的常用方法：

1. **[[碎石图（Scree Plot）|碎石图拐点]]**：选择曲线由陡变缓附近的主成分数；
2. **累计解释方差**：例如选择达到 80%、90% 或 95% 的最小 $k$，阈值应结合任务而定；
3. **下游任务的交叉验证**：若 PCA 用于预测，把 $k$ 当作[[超参数]]，根据验证误差选择；
4. **可解释性与计算成本**：在信息保留、模型复杂度和解释难度之间权衡。

> [!warning] 没有通用的“正确阈值”
> 不能机械地认为累计解释方差达到 85% 就一定足够。可视化、压缩、去噪和预测任务对 $k$ 的要求不同；碎石图的拐点也可能不明显。

## 5. 是否需要标准化

PCA 对变量尺度敏感，因为方差较大的变量会更强地影响主成分。

### 通常应标准化

- 各变量单位不同，例如“收入（元）”“年龄（岁）”“点击率（%）”；
- 各变量数值范围差异很大；
- 不希望某变量仅因量纲较大而主导 PCA。

此时对标准化数据做 PCA，相当于基于**相关矩阵**分析。

### 可以不标准化

- 所有变量单位相同、尺度相近；
- 原始方差大小本身具有明确意义；
- 研究者确实希望高方差变量拥有更大权重。

> [!important] 至少要中心化
> 常规 PCA 必须先中心化。R 的 `prcomp()` 默认 `center = TRUE`，但默认 `scale. = FALSE`；是否标准化需要主动判断。

## 6. 如何解释 PCA 结果

### 6.1 载荷（loadings）

载荷描述每个原始变量对主成分方向的贡献：

- 绝对值越大，该变量越影响这个主成分；
- 同号变量沿该主成分同向变化；
- 异号变量沿该主成分形成对比；
- 应结合多个较大绝对值载荷和领域知识给主成分命名。

例如，若 PC1 在点击量、浏览时长、购买次数上均有较大的同号载荷，可暂时解释为“综合活跃度”。

> [!note] 载荷正负号没有唯一方向
> 同一个载荷向量整体乘以 $-1$ 仍表示同一条轴。因此不同软件或不同运行中主成分符号相反，并不代表结果矛盾；对应得分也会同时反号。

### 6.2 得分（scores）

得分是每个样本在新坐标轴上的位置：

- 得分相近的样本，在被保留的主成分空间中具有相似特征；
- PC1—PC2 得分图可用于观察群组、趋势和离群点；
- 二维图只展示部分总方差，不能把图上距离直接等同于完整高维距离。

### 6.3 双标图（biplot）

双标图同时展示样本得分和变量方向，可用于观察：

- 哪些变量对 PC1、PC2 贡献较大；
- 哪些变量方向相近或相反；
- 哪些样本在某些变量方向上更突出。

图中样本点和变量箭头可能使用不同缩放方式，因此不要把箭头端点与样本点作简单的绝对距离比较。

## 7. R：使用 `prcomp()` 完成 PCA

课程代码使用 `USArrests` 数据：

```r
data("USArrests")

# 四个变量量纲和方差不同，因此进行标准化
pca <- prcomp(USArrests, center = TRUE, scale. = TRUE)

# 查看结果概览
summary(pca)
names(pca)
```

### 7.1 `prcomp()` 结果对象

| 对象 | 含义 |
|---|---|
| `pca$center` | 训练数据各变量的均值 |
| `pca$scale` | 训练数据各变量的标准差 |
| `pca$rotation` | 载荷矩阵；每列对应一个主成分 |
| `pca$x` | 训练样本的主成分得分 |
| `pca$sdev` | 各主成分得分的标准差 |

```r
pca$rotation       # 解释变量对各主成分的贡献
head(pca$x)        # 查看前几个样本的主成分得分
pca$sdev^2         # 各主成分的方差（特征值）
```

### 7.2 计算解释方差比例

```r
pc_var <- pca$sdev^2
pve <- pc_var / sum(pc_var)
cpve <- cumsum(pve)

data.frame(
  PC = seq_along(pve),
  PVE = pve,
  Cumulative_PVE = cpve
)
```

### 7.3 绘制解释方差图

```r
par(mfrow = c(1, 2))

plot(
  pve,
  type = "b",
  xlab = "Principal Component",
  ylab = "Proportion of Variance Explained",
  ylim = c(0, 1)
)

plot(
  cpve,
  type = "b",
  xlab = "Principal Component",
  ylab = "Cumulative Proportion of Variance Explained",
  ylim = c(0, 1)
)

par(mfrow = c(1, 1))
```

也可使用基础函数快速查看：

```r
screeplot(pca, type = "lines")
biplot(pca, scale = 0)
```

### 7.4 选择达到目标累计解释方差的最小 $k$

```r
target <- 0.90
k <- which(cpve >= target)[1]
k

# 降维后的训练数据
train_pc <- pca$x[, seq_len(k), drop = FALSE]
```

### 7.5 将训练所得 PCA 应用于新数据

```r
# predict() 会复用训练阶段的中心、尺度和载荷
new_pc <- predict(pca, newdata = new_data)
new_pc <- new_pc[, seq_len(k), drop = FALSE]
```

> [!important] 防止[[数据泄漏（Data Leakage）|数据泄漏]]
> 应先划分训练集与测试集，只用训练集拟合 `prcomp()`；再用 `predict()` 将同一个 PCA 变换应用于验证集、测试集和未来数据。不能先对全体数据做 PCA 再划分。

```r
# 正确流程示意
pca <- prcomp(train_x, center = TRUE, scale. = TRUE)
train_pc <- predict(pca, newdata = train_x)[, seq_len(k), drop = FALSE]
test_pc  <- predict(pca, newdata = test_x)[, seq_len(k), drop = FALSE]
```

## 8. 从特征值分解到 SVD

理论上可对协方差矩阵进行特征值分解；实际计算中，`prcomp()` 使用数据矩阵的**奇异值分解**（SVD），通常数值稳定性更好。

若

$$
X_c=UDV^T,
$$

则：

- $V$ 的列是 PCA 载荷方向；
- $Z=X_cV=UD$ 是主成分得分；
- 第 $m$ 个特征值满足 $\lambda_m=d_m^2/(n-1)$。

因此，“协方差矩阵的特征值分解”和“中心化数据矩阵的 SVD”是 PCA 的两种等价计算视角。

## 9. PCA 用于后续建模

将前 $k$ 个主成分输入线性回归，称为**主成分回归**（Principal Components Regression, PCR）：

```r
fit <- lm(y ~ ., data = data.frame(y = train_y, train_pc))
pred <- predict(fit, newdata = data.frame(test_pc))
```

这样可以减少输入维度并消除主成分之间的线性相关，但要注意：

- PCA 选择方向时没有查看 $Y$；
- 低方差主成分也可能与 $Y$ 强相关；
- 因此主成分数量应尽量通过完整建模管道中的交叉验证选择，而不能只看累计解释方差；
- 所有预处理步骤都应在每个交叉验证训练折内部重新拟合。

课程中的 `CEPA(1).R` 展示了 `PCA + OLS` 的基本思路。实际对新数据变换时，应优先使用 `predict(pca, newdata = ...)`，以确保严格复用训练集的中心和尺度。

## 10. PCA 与相近方法辨析

| 方法                                | 主要目标         |  是否线性 | 是否使用标签 $Y$ | 结果特点            |     |
| --------------------------------- | ------------ | ----: | ---------: | --------------- | --- |
| PCA                               | 最大化投影方差、低秩重构 |     是 |          否 | 主成分为原变量的正交线性组合  |     |
| [[特征选择（Feature Selection）\|特征选择]] | 保留部分原始变量     | 视方法而定 |      视方法而定 | 仍保留原变量含义        |     |
| [[K-Means]]                       | 将样本分成 $K$ 个簇 |     — |          否 | 输出簇标签和聚类中心      |     |
| [[t-SNE]]                         | 强调局部邻域的低维可视化 |     否 |          否 | 适合展示，不宜直接解释全局距离 |     |
| [[UMAP]]                          | 非线性流形降维与可视化  |     否 |        通常否 | 常用于二维或三维嵌入      |     |
| 因子分析                              | 用潜在因子解释变量相关性 |     是 |          否 | 显式区分公共方差与特有误差   |     |

> [!note] PCA 不是特征选择
> 特征选择从原始变量中挑出一部分；PCA 将原始变量组合成新的主成分。PCA 常能有效压缩信息，但新变量的业务含义通常不如原始特征直接。

## 11. 局限与常见误区

### 11.1 主要局限

- **只能捕捉线性方向**：弯曲流形等非线性结构可能需要 UMAP、t-SNE 或自动编码器；
- **对尺度敏感**：是否标准化会显著改变结果；
- **对异常值敏感**：极端观测会影响均值、协方差和主成分方向；
- **解释性可能下降**：每个主成分通常混合多个原始变量；
- **高方差不等于高预测价值**：因为 PCA 不使用 $Y$；
- **类别变量不能直接照搬处理**：普通 PCA 主要面向数值变量，类别数据需先采用合适编码或其他方法。

### 11.2 高频错误

1. 未判断量纲就直接使用 `scale. = FALSE`；
2. 对全体数据拟合 PCA 后再划分训练集与测试集；
3. 把载荷当作样本得分，或把得分当作变量贡献；
4. 认为主成分符号变化表示模型出错；
5. 只凭 PC1—PC2 图就断言高维空间中存在清晰聚类；
6. 机械使用 80%、85% 或 95% 阈值，不结合下游任务；
7. 认为“不相关”就等同于“相互独立”。

## 12. 考试与复习速记

> [!summary] 核心结论
> 1. PCA 是无监督、线性的降维方法；
> 2. PC1 是方差最大的单位长度线性组合；
> 3. 后续主成分与之前方向正交，并解释剩余方差；
> 4. 载荷是“变量如何组成主成分”，得分是“样本在主成分上的坐标”；
> 5. 特征值等于对应主成分的方差；
> 6. 解释方差比例为 $\lambda_m/\sum_j\lambda_j$；
> 7. 不同量纲通常先标准化；
> 8. PCA 必须只在训练集上拟合，再应用于其他数据；
> 9. 高方差方向未必最能预测 $Y$；
> 10. `prcomp()` 中最常用的是 `rotation`、`x`、`sdev`、`center` 和 `scale`。
