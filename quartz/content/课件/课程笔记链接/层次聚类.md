# 层次聚类（Hierarchical Clustering）

> [!abstract] 一句话概括
> 层次聚类是一种**无监督聚类方法**：它根据样本之间的距离，逐步合并或拆分簇，并用一棵**树状图（dendrogram）**展示从细到粗的多层分组结构。

## 1. 层次聚类解决什么问题

给定 $n$ 个没有类别标签的样本，层次聚类：

- 同一簇内的样本尽量相似；
- 不同簇之间的样本尽量不同；
- 不只输出某一个固定分组，还展示样本从小簇到大簇的嵌套关系。

常见用途包括客户分群、基因表达分析、文档分组和探索性数据分析。

与 [[K-Means]] 不同，运行层次聚类之前通常**不必先指定簇数 $K$**。但是，如果最终需要确定每个样本属于哪一簇，仍然要在树状图上选择切割高度，或指定最终簇数。

## 2. 两种基本类型

### 2.1 凝聚型层次聚类

凝聚型层次聚类（Agglomerative Hierarchical Clustering）采用“**自底向上**”的过程：

1. 开始时，每个样本各自构成一个簇；
2. 找到距离最近的两个簇并合并；
3. 根据所选联动方式，重新计算新簇与其他簇之间的距离；
4. 重复合并，直到所有样本成为一个大簇。

R 基础函数 `hclust()` 实现的就是这种凝聚型方法，也是课程中的重点。

### 2.2 分裂型层次聚类

分裂型层次聚类（Divisive Hierarchical Clustering）采用“**自顶向下**”的过程：

1. 开始时，所有样本属于同一个簇；
2. 逐步将大簇拆分为更小的簇；
3. 直到每个样本单独成簇，或满足停止条件。

> [!note] 本笔记的默认含义
> 如果没有特别说明，下面的“层次聚类”主要指课程使用的**凝聚型层次聚类**。

## 3. 核心算法

设初始时有 $n$ 个簇：

$$
C_1=\{x_1\},\ C_2=\{x_2\},\ldots,C_n=\{x_n\}.
$$

每轮操作为：

1. 计算所有簇之间的差异度；
2. 找到差异度最小的两个簇；
3. 将二者合并为一个新簇；
4. 更新新簇与其他簇之间的距离。

每合并一次，簇数就减少 1。因此，从 $n$ 个单样本簇合并为一个总簇，需要进行 $n-1$ 次合并。

> [!important] 两个需要分别决定的问题
> - **样本之间有多远？**由距离度量决定；
> - **两个簇之间有多远？**由[[层次聚类#5. 簇之间的联动方式|联动方式（linkage）]]决定。

## 4. 样本之间的距离

### 4.1 欧氏距离

数值型数据最常用欧氏距离：

$$
d(x_i,x_j)
=\sqrt{\sum_{r=1}^{p}(x_{ir}-x_{jr})^2}.
$$

R 中 `dist(x)` 默认计算欧氏距离。

### 4.2 曼哈顿距离

$$
d(x_i,x_j)
=\sum_{r=1}^{p}|x_{ir}-x_{jr}|.
$$

与平方差相比，曼哈顿距离对单个维度上的极端差异相对没有那么敏感：

```r
d <- dist(x, method = "manhattan")
```

### 4.3 其他差异度

还可以根据数据特点使用相关性距离、二元变量差异度等。距离的选择必须与变量类型和研究问题匹配，不能对所有数据机械使用欧氏距离。

> [!warning] 特征尺度会改变聚类结果
> 如果“年收入”的数值范围是数十万，而“年龄”的范围只有几十，欧氏距离可能几乎由年收入决定。因此，不同单位或尺度的数值特征通常应先进行[[数据标准化（Standardization）|标准化]]。

```r
x_scaled <- scale(x)
d <- dist(x_scaled)
```

## 5. 簇之间的联动方式

假设 $A$、$B$ 是两个簇，$d(i,j)$ 是样本 $i$ 与样本 $j$ 之间的距离。联动方式规定如何把多个点之间的距离汇总成“簇间距离”。

### 5.1 单联动

单联动（Single Linkage）取两个簇中**最近的一对样本**：

$$
D_{\text{single}}(A,B)
=\min_{i\in A,\,j\in B}d(i,j).
$$

- 优点：可能识别细长或不规则形状的簇；
- 局限：容易出现**链化效应**，即若干点像链条一样把本应分开的群体连接起来。

### 5.2 完全联动

完全联动（Complete Linkage）取两个簇中**最远的一对样本**：

$$
D_{\text{complete}}(A,B)
=\max_{i\in A,\,j\in B}d(i,j).
$$

- 倾向于产生较紧凑、直径较小的簇；
- 对极端样本和离群点可能比较敏感。

`hclust()` 默认使用完全联动。

### 5.3 平均联动

平均联动（Average Linkage）取两个簇中所有跨簇样本对距离的平均值：

$$
D_{\text{average}}(A,B)
=\frac{1}{|A||B|}
\sum_{i\in A}\sum_{j\in B}d(i,j).
$$

它在单联动与完全联动之间进行折中，通常比只看最近点或最远点更稳定。

### 5.4 中心联动

中心联动（Centroid Linkage）计算两个簇中心之间的距离：

$$
D_{\text{centroid}}(A,B)
=\|\bar{x}_A-\bar{x}_B\|_2.
$$

中心联动有时会出现树状图“倒置”：后一次合并的高度可能低于前一次合并的高度，因此解读时需要谨慎。

### 5.5 Ward 法

Ward 法每次选择使**簇内平方和增加最少**的合并：

$$
\Delta(A,B)
=\operatorname{WSS}(A\cup B)
-\operatorname{WSS}(A)
-\operatorname{WSS}(B).
$$

它倾向于得到紧凑、大小较均衡的簇。在 R 中通常使用：

```r
hc_ward <- hclust(dist(x_scaled), method = "ward.D2")
```

> [!tip] 常用选择
> 没有一种联动方式适合所有数据。实践中可以把完全联动、平均联动和 Ward 法作为重点候选，再结合树状图、聚类稳定性、轮廓系数和领域知识比较。单联动尤其需要注意链化效应。

## 6. 如何阅读树状图

下面是一棵简化的树状图：

```text
差异度/合并高度
  ↑
7 │             ┌───────────────┐
  │             │               │
4 │        ┌────┴────┐          │
  │        │         │          │
2 │     ┌──┴──┐      │       ┌──┴──┐
  │     │     │      │       │     │
0 └──── A     B      C       D     E ──→ 样本
```

### 6.1 叶节点

树最底部的 A、B、C、D、E 是原始样本。

### 6.2 合并高度

两条分支相遇时的纵轴高度表示它们合并时的差异度：

- A 与 B 在较低位置合并，说明二者比较相似；
- D 与 E 也较早合并；
- 两个大分支在高度 7 才合并，说明它们差异较大。

### 6.3 横向位置

叶节点的左右顺序主要是为了画图清楚。判断样本是否相似，应看它们在**多高的位置首次汇合**，不能只看图上横向距离。

### 6.4 水平切割

在某个高度画一条水平线，水平线穿过几条主要分支，就得到几个簇：

```text
             ┌───────────────┐
-------------切割线-------------
        ┌────┴────┐       ┌──┴──┐
        │         │       │     │
     ┌──┴──┐      │       │     │
     A     B      C       D     E

结果：{A, B, C} 和 {D, E}，共 2 个簇
```

> [!important] 树状图表示嵌套关系
> 如果在较高位置切割，得到的簇较少、较粗；如果在较低位置切割，得到的簇较多、较细。层次聚类的价值在于可以在同一棵树上观察多个粒度的分组。

## 7. 如何决定簇数

层次聚类虽然不要求在算法开始前指定 $K$，但得到最终分组时仍要决定切成几簇。常用依据包括：

1. **树状图中的明显高度跳跃**：若相邻两次合并高度差很大，可考虑在大跳跃之前切割；
2. **轮廓系数（silhouette coefficient）**：比较不同 $K$ 下簇内紧密度与簇间分离度；
3. **聚类稳定性**：改变样本或进行重采样后，分组是否仍然相似；
4. **领域知识与可解释性**：簇是否具有实际含义，规模是否适合后续使用；
5. **多种联动方式比较**：结论是否严重依赖某一种距离或联动规则。

> [!warning] 不要只追求图形“好看”
> 聚类没有真实标签时，通常不存在唯一正确的 $K$。应综合统计指标、稳定性和实际用途，而不是只凭肉眼挑选最整齐的树状图。

## 8. R：课程示例

课程 `Lec 10.R` 首先生成二维模拟数据 `x`，然后比较三种联动方式：

```r
# 样本之间的欧氏距离
d <- dist(x)

# 三种簇间距离定义
hc_complete <- hclust(d, method = "complete")
hc_average  <- hclust(d, method = "average")
hc_single   <- hclust(d, method = "single")

par(mfrow = c(1, 3))
plot(hc_complete, main = "Complete Linkage",
     xlab = "", sub = "", cex = 0.9)
plot(hc_average, main = "Average Linkage",
     xlab = "", sub = "", cex = 0.9)
plot(hc_single, main = "Single Linkage",
     xlab = "", sub = "", cex = 0.9)
par(mfrow = c(1, 1))
```

即使输入数据相同，不同联动方式也可能产生不同的合并顺序和最终分组。

### 8.1 切割树状图

可以按簇数切割：

```r
cluster_2 <- cutree(hc_complete, k = 2)
cluster_4 <- cutree(hc_complete, k = 4)

table(cluster_2)
cluster_2
```

也可以按树状图高度切割：

```r
cluster_h <- cutree(hc_complete, h = 4)
```

`k` 和 `h` 通常二选一：`k` 直接指定簇数，`h` 指定切割高度。

### 8.2 在树状图上标出簇

```r
plot(hc_complete, main = "Complete Linkage",
     xlab = "", sub = "", cex = 0.9)
rect.hclust(hc_complete, k = 4, border = 2:5)
```

### 8.3 `hclust()` 结果对象

| 对象 | 含义 |
|---|---|
| `hc$merge` | 每一步合并了哪些样本或簇 |
| `hc$height` | 每一步合并发生的高度 |
| `hc$order` | 树状图中叶节点的绘制顺序 |
| `hc$labels` | 样本标签 |
| `hc$method` | 使用的联动方式 |
| `hc$dist.method` | 原始样本距离的计算方式 |

```r
hc_complete$height
hc_complete$merge
hc_complete$order
```

## 9. R：使用 `USArrests` 的完整流程

```r
data("USArrests")

# 1. 标准化：各变量尺度和方差不同
x <- scale(USArrests)

# 2. 计算距离
d <- dist(x, method = "euclidean")

# 3. 凝聚型层次聚类
hc <- hclust(d, method = "complete")

# 4. 绘制树状图
plot(hc, labels = rownames(USArrests),
     main = "Hierarchical Clustering of USArrests",
     xlab = "", sub = "")

# 5. 切成 4 个簇并画框
groups <- cutree(hc, k = 4)
rect.hclust(hc, k = 4, border = 2:5)

# 6. 查看分组及各簇原始变量均值
groups
aggregate(USArrests, by = list(cluster = groups), mean)
```

这里的簇编号只是标签，没有大小或好坏顺序；换一种联动方式后，编号和成员都可能变化。

## 10. 与 K-Means 的区别

| 对比项 | 层次聚类 | [[K-Means]] |
|---|---|---|
| 是否预先指定 $K$ | 建树前不需要，切树时再决定 | 训练前必须指定 |
| 输出形式 | 树状图和不同层级的分组 | 一个固定的 $K$ 簇划分 |
| 核心选择 | 距离度量、联动方式、切割位置 | $K$、初始中心、迭代结果 |
| 随机初始化 | 基础 `hclust()` 通常不需要 | 通常需要，且建议多次初始化 |
| 是否可回退 | 一旦合并，后续不会拆开 | 样本可在迭代中改变所属簇 |
| 新样本分配 | 没有天然的直接预测规则 | 可按最近聚类中心分配 |
| 大数据扩展性 | 距离矩阵开销较大 | 通常更适合较大数据集 |

> [!note] 二者并非谁一定更好
> 层次聚类适合观察嵌套结构和探索不同簇数；K-Means 计算通常更快，适合近似球状、规模较大的数值型数据。

## 11. 新样本与计算成本

### 11.1 新样本不能直接 `predict()`

基础层次聚类没有像回归、分类或 K-Means 那样自然的预测规则。加入新样本后，距离结构和树都可能发生变化。

若需要持续为新样本分组，可以考虑：

- 重新进行层次聚类；
- 根据已有簇构造最近中心或最近邻规则；
- 把已有簇标签作为临时标签，再训练分类模型。

### 11.2 对大样本的限制

$n$ 个样本需要大约 $n(n-1)/2$ 个成对距离，因此距离矩阵的存储开销为 $O(n^2)$。样本数很大时，内存和计算时间都会迅速增加。

可考虑先抽样探索、先用 [[主成分分析（PCA）]] 降维，或改用更适合大数据的聚类算法。但 PCA 降维也会改变距离结构，应验证结果是否稳定。

## 12. 常见误区

1. **认为不必指定 $K$ 就永远不用选簇数**：建树时不需要，但获得最终分组时仍需切树；
2. **只看叶节点横向距离**：真正重要的是样本在多高的位置首次合并；
3. **忽略标准化**：量纲大的变量可能主导距离；
4. **混淆样本距离与簇间联动**：`dist()` 和 `hclust(method = ...)` 决定的是两个不同层面；
5. **认为树状图可以证明真实类别存在**：聚类始终会给出结构，即使数据中没有清晰群组；
6. **只尝试一种联动方式**：结果可能对联动规则非常敏感；
7. **将簇编号当作顺序变量**：簇 1、簇 2 只是名称；
8. **认为同簇样本一定完全相似**：聚类只是在给定距离和算法规则下进行相对分组；
9. **忽略异常值和缺失值**：异常值会改变距离，基础 `dist()` 也要求妥善处理缺失数据；
10. **直接把已有树用于任意新样本**：基础层次聚类没有通用 `predict()` 方法。

## 13. 考试与复习速记

> [!summary] 核心结论
> 1. 层次聚类是无监督学习方法，结果用树状图表示；
> 2. 凝聚型方法从每个样本单独成簇开始，反复合并最近的两个簇；
> 3. `dist()` 决定样本间距离，`hclust()` 的 `method` 决定簇间距离；
> 4. 单联动取最小距离，完全联动取最大距离，平均联动取平均距离；
> 5. Ward 法选择使簇内平方和增加最少的合并；
> 6. 树状图纵轴表示合并差异度，横向顺序通常没有直接数值意义；
> 7. 在树状图上水平切割可得到最终簇；
> 8. 层次聚类建树前不需要指定 $K$，但最终分组仍需选择切割位置；
> 9. 不同尺度的特征通常需要先标准化；
> 10. R 的核心流程是 `scale()` → `dist()` → `hclust()` → `plot()` → `cutree()`。
