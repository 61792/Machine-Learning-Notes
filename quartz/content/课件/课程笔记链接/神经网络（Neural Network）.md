# 神经网络
也称人工神经网络ANN（**Artificial Neural Network**）
## 1. 神经网络的通用结构

大多数神经网络都可以拆成三部分：

```text
输入层 → 特征提取/隐藏层 → 输出层
```

### 输入层

负责接收数据：

- 表格数据：$p$ 个变量；
- 图像：高度 × 宽度 × 通道；
- 文本：词元序列；
- 时间序列：时间步 × 特征。

### 隐藏层或主干网络

负责学习特征，是不同架构的主要区别：

- MLP 使用全连接层；
- CNN 使用卷积层；
- RNN 使用循环状态；
- Transformer 使用注意力；
- GNN 使用邻居信息聚合。

### 输出层

根据任务产生最终结果：

| 任务    | 输出设计                            |
| ----- | ------------------------------- |
| 二分类   | 1 个 logit，预测时通过 Sigmoid 转为概率    |
| 多分类   | $K$ 个 logits，预测时通过 Softmax 转为概率 |
| 多标签分类 | $K$ 个独立 logits，每个标签使用 Sigmoid   |
| 回归    | 1 个或多个连续数值                      |
| 序列生成  | 每个位置输出词表概率                      |

## 2. 神经网络参数
**神经网络的参数（Parameters）**通常由两部分组成：权重（Weights，即连线） 和 偏置（Biases，即每个神经元自带的截距项）。

可以把每个神经元理解成一个小函数。它先做一件事：
$(z = b_0 + b_1x_1 + b_2x_2 + \cdots + b_px_p)$

然后再通过激活函数：
$[ a = g(z) ]$

所以一个神经元完整地看，其实是：
$[ a = g(b_0+b_1x_1+\cdots+b_px_p) ]$

这里的 $b_0$ 就是偏置，也就是这个神经元自己的截距项。

神经元输出= 激活函数加权求和+偏置$= g(b_0+b_1x_1+\cdots+b_px_p)$

$g(z)=\max(0,z)$

含义是：第一隐藏层第 $j$个节点先把 4 个输入变量加权求和，再加上偏置项，最后经过 ReLU 函数。
