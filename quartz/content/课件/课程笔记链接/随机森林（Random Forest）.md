# 随机森林（Random Forest）

> [!abstract] 一句话概括
> 随机森林（Random Forest, RF）是一种以[[分类器#2.4 决策树（Decision Tree）|决策树]]为基模型的[[集成学习]]方法。它通过 Bootstrap 抽样和随机选择候选特征训练许多棵差异化的树，再用投票或平均得到最终预测。

## 1. 基本思想

单棵决策树容易受到训练数据扰动的影响，属于方差较高的模型。随机森林不依赖一棵树，而是训练许多棵有差异的树，再汇总它们的预测：

- **分类任务**：多数投票，或平均各树的类别概率；
- **回归任务**：计算各树预测值的平均数。

如果多棵树都具有一定预测能力，并且它们所犯的错误不完全相同，集成结果通常比单棵树更加稳定。

## 2. 随机性来自哪里

随机森林使用两层随机性。

### 2.1 样本随机：Bootstrap

从原训练集进行有放回抽样，为每棵树生成不同的 Bootstrap 训练集。某些样本会重复出现，某些样本不会被抽中。

没有进入某棵树训练集的样本称为**袋外样本（Out-of-Bag, OOB）**，可用于估计该树及整个森林的泛化误差。

### 2.2 特征随机：随机候选特征

普通 Bagging 树在每次节点切分时可以查看全部 $p$ 个特征；随机森林只随机抽取其中 $m$ 个特征作为候选，再从中选择最佳切分。

这种做法可以防止所有树都反复依赖同一个强特征，从而降低树之间的相关性。

因此：

$$
\text{随机森林}
=\text{Bootstrap 抽样}
+\text{多棵决策树}
+\text{随机候选特征}
+\text{投票或平均}.
$$

当 $m=p$、其他设置相同时，随机森林就退化为普通 Bagging 树。

## 3. 训练过程

假设需要训练 $B$ 棵树：

1. 对第 $b$ 棵树生成一个 Bootstrap 训练集；
2. 从根节点开始生长决策树；
3. 每次节点切分时，从全部特征中随机抽取 $m$ 个候选特征；
4. 仅在这 $m$ 个特征中寻找最佳切分；
5. 重复以上过程，得到 $B$ 棵树；
6. 对所有树的预测进行投票或平均。

随机森林中的树通常不需要像单棵解释型决策树那样进行强剪枝，因为最终预测会对多棵树取平均。

## 4. 为什么能够降低方差

假设每棵树的预测方差约为 $\sigma^2$，树与树之间的平均相关系数为 $\rho$，则 $B$ 棵树平均后的方差可近似写为：

$$
\operatorname{Var}(\bar f)
\approx
\rho\sigma^2+
\frac{1-\rho}{B}\sigma^2.
$$

这说明：

- 增加树的数量 $B$，可以减小第二项；
- 降低树之间的相关性 $\rho$，可以进一步降低整体方差；
- 随机候选特征的主要作用，正是让不同树更加多样化。

> [!important]
> 随机森林通常能降低单棵树的方差和过拟合风险，但不能保证完全消除过拟合，也不一定在所有数据集上都是最优模型。

## 5. 分类与回归

### 5.1 随机森林分类

适用于离散类别预测，例如客户流失、信用违约和疾病分类。第 $b$ 棵树给出类别预测 $\hat y^{(b)}$，最终选择票数最多的类别。

可使用[[混淆矩阵、ROC与AUC|混淆矩阵、ROC 和 AUC]]评估分类性能，并根据业务成本调整[[阈值]]。

### 5.2 随机森林回归

适用于连续数值预测，例如房价、销售额和需求量。最终预测为：

$$
\hat f_{\mathrm{RF}}(x)
=\frac{1}{B}\sum_{b=1}^{B}\hat f^{(b)}(x).
$$

常见指标包括 MAE、MSE、RMSE 和 $R^2$。

## 6. 主要超参数

| 超参数 | 含义 | 典型影响 |
|---|---|---|
| 树的数量 $B$ | 森林中决策树的数量 | 更多树通常更稳定，但计算和存储成本增加 |
| `mtry` / `max_features` | 每次切分考虑的候选特征数 | 越小则树的差异更大，但单棵树可能变弱 |
| 最大深度 | 每棵树允许的最大深度 | 控制树的复杂度 |
| 最小叶节点样本数 | 叶节点至少包含多少样本 | 较大时预测更平滑 |
| Bootstrap 样本比例 | 每棵树抽取多少训练样本 | 影响树之间的差异与训练成本 |
| 类别权重 | 不同类别的错误代价 | 可帮助处理类别不平衡 |

增加树的数量通常不会像增加单棵树深度那样直接导致严重过拟合，但在性能趋于稳定后继续增加树，只会提高计算成本。

## 7. 特征重要性

随机森林常见的特征重要性包括：

1. **基于不纯度下降的重要性**：统计特征参与切分时带来的不纯度下降；计算快，但可能偏向取值较多或连续型特征。
2. **置换重要性（Permutation Importance）**：打乱某个特征后观察模型性能下降程度；解释更直观，但相关特征可能互相替代，使单个变量的重要性被低估。

> [!warning]
> 特征重要性表示变量对预测的贡献，不自动等于因果作用。高度相关的变量也会使重要性解释变得困难。

## 8. 优点与局限

| 优点 | 局限 |
|---|---|
| 能表示复杂的非线性关系和特征交互 | 不如单棵树和线性模型容易解释 |
| 通常比单棵决策树稳定 | 树多时模型较大，预测和存储成本增加 |
| 对特征缩放通常不敏感 | 对超高维稀疏数据未必是最佳选择 |
| 可同时用于分类和回归 | 不能自然外推到训练目标范围之外 |
| 可以利用 OOB 样本估计误差 | 类别极不平衡时需要额外处理 |
| 能提供特征重要性 | 重要性可能存在偏差，不能直接作因果解释 |

## 9. 与相关方法的区别

| 方法 | 核心特点 | 与随机森林的关系 |
|---|---|---|
| 单棵决策树 | 一棵树直接预测 | 易解释，但方差高、稳定性较差 |
| Bagging 树 | Bootstrap 多棵树，每次切分查看所有特征 | 随机森林在此基础上增加随机候选特征 |
| 随机森林 | Bootstrap 多棵树 + 随机候选特征 | 通过降低树的相关性改善集成效果 |
| Boosting 树 | 后一棵树依次纠正前面模型的错误 | 串行训练；随机森林通常可并行训练 |

Bootstrap、Bagging、Boosting 和 Stacking 的完整关系参见[[集成学习]]。

## 10. R 中的基本实现

### 10.1 使用 `randomForest`

```r
library(randomForest)

set.seed(123)
rf_fit <- randomForest(
  Species ~ .,
  data = iris,
  ntree = 500,
  mtry = 2,
  importance = TRUE
)

print(rf_fit)          # 包含 OOB 误差
predict(rf_fit, iris)  # 类别预测
importance(rf_fit)     # 特征重要性
```

### 10.2 使用 `ranger`

```r
library(ranger)

set.seed(123)
rf_fit <- ranger(
  Species ~ .,
  data = iris,
  num.trees = 500,
  mtry = 2,
  importance = "permutation",
  probability = TRUE
)

rf_fit$prediction.error
predict(rf_fit, iris)$predictions
```

实际建模时，应在训练集上调参，并在独立测试集或交叉验证中报告最终性能，不能只根据训练准确率或 OOB 误差判断模型优劣。

## 11. 核心总结

- 随机森林是以决策树为基模型的 Bagging 集成模型。
- 两层随机性分别来自 Bootstrap 样本和每次切分时的随机候选特征。
- 分类时投票或平均概率，回归时平均预测值。
- 随机候选特征降低树之间的相关性，使集成平均更有效。
- OOB 样本可估计泛化误差，但最终结果仍应使用合理的数据划分进行验证。
- 随机森林通常是表格数据的强基线，但并非所有任务中都最准确，也不能完全取代可解释性分析。
