# 特征值与特征向量

> [!abstract] 学习定位
> 理解矩阵变换中方向保持不变的特殊轴及其缩放大小。

## 需要掌握

- [ ] 理解 Av=λv
- [ ] 知道对称矩阵具有正交特征向量
- [ ] 能把特征值与解释方差联系起来

## 服务于哪些模型环节

| 模型或方法 | 具体用途                                                                 |
| ----- | -------------------------------------------------------------------- |
| PCA   | 分解协方差矩阵：特征向量是载荷方向，特征值是主成分方差<br>- 特征向量 → 主成分方向；<br>- 特征值 → 该主成分解释的方差。 |
| 谱聚类   | 利用图拉普拉斯矩阵的特征向量嵌入                                                     |
| 稳定性分析 | 用特征值描述线性变换的主要方向                                                      |
中心化数据 Xc
      ↓
协方差矩阵 S
      ↓
特征值分解
      ↓
主成分方向与解释方差
