# 1. 线性代数

## 第一组：数据表示与基本运算

1. [ ] [[课件/数学基础/向量、矩阵与张量|向量、矩阵与张量]]：掌握样本、特征、参数和批量数据在数学中的表示方式。
2. [ ] [[课件/数学基础/矩阵乘法、转置与维度|矩阵乘法、转置与维度]]：理解线性模型、PCA 得分、神经网络前向传播中的矩阵运算。

## 第二组：向量空间与几何结构

3. [ ] [[课件/数学基础/内积、范数与距离|内积、范数与距离]]：建立向量长度、夹角、距离和模型复杂度惩罚的共同语言。
4. [ ] [[课件/数学基础/线性相关、矩阵秩与逆|线性相关、矩阵秩与逆]]：理解信息方向、参数可识别性、多重共线性和最小二乘解的稳定性。
5. [ ] [[课件/数学基础/正交投影与基变换|正交投影与基变换]]：理解把样本投影到新坐标轴，以及不同基之间的坐标转换。

## 第三组：统计矩阵与矩阵分解

6. [ ] [[课件/数学基础/协方差矩阵|协方差矩阵]]：把所有变量的方差和两两协方差组织成一个对称矩阵。
7. [ ] [[课件/数学基础/特征值与特征向量|特征值与特征向量]]：理解矩阵变换中方向保持不变的特殊轴及其缩放大小。
8. [ ] [[课件/数学基础/奇异值分解（SVD）|奇异值分解（SVD）]]：把任意矩阵分解为旋转、缩放和再旋转，支持降维与稳定计算。

## 第四组：神经网络专项

9. [ ] [[课件/数学基础/卷积运算|卷积运算]]：理解卷积核在局部窗口上的加权求和与参数共享。
