# 机器学习方法总览

## 1. 概念

### <span style="color: #1E5AA8;">1.1四个层级</span>

学习机器学习时，最容易混淆的是把“任务”“学习范式”“算法”和“网络架构”放在同一层比较。

| 层级                                       | 回答的问题       | 示例                            |
| ---------------------------------------- | ----------- | ----------------------------- |
| <font color="#ff0000">**学习范式**</font>    | 模型从什么反馈中学习？ | 监督学习、无监督学习、自监督学习、强化学习         |
| <font color="#ff0000">**任务类型**</font>    | 最终要解决什么问题？  | 分类、回归、聚类、降维、异常检测、生成           |
| <font color="#ff0000">**算法/模型家族**</font> | 用什么数学机制解决？  | 逻辑回归、KNN、决策树、SVM、K-Means、神经网络 |
| <font color="#ff0000">**神经网络架构**</font>  | 神经网络内部怎样组织？ | MLP、CNN、RNN、Transformer、GNN   |

例如：
> “识别图片中的猫和狗”是**分类任务**；可以采用**监督学习**；具体模型可以是逻辑回归、SVM 或神经网络；处理图片时常选用 **CNN 架构**。

> [!important] 分类器与聚类器
> - **分类器**从带标签数据中学习已有类别，再预测新样本属于哪一类。
> - **聚类算法**在没有类别标签时探索数据中可能存在的群组。
> - 因此 [[K-Means]] 是聚类算法，通常不叫分类器；[[分类器#2.3 K 最近邻（K-Nearest Neighbors, KNN）|KNN]] 则可以是分类器。

### <span style="color: #1E5AA8;">1. 2人工智能、机器学习与深度学习的关系</span>

```text
人工智能（Artificial Intelligence, AI）
└── 机器学习（Machine Learning, ML）
    ├── 传统机器学习方法
    │   ├── 线性/广义线性模型
    │   ├── 距离与邻居方法
    │   ├── 树模型与集成学习
    │   ├── 核方法
    │   └── 聚类与降维方法
    └── 神经网络（Artificial Neural Network, ANN）
        ├── 浅层神经网络
        |   ├── 单层感知机
        └── 深度学习（Deep Learning, DL）
            ├── MLP / 深度前馈网络
            ├── CNN
            ├── RNN / LSTM / GRU
            ├── Transformer
            └── GNN、自动编码器、GAN、扩散模型等
```

这里需要注意：

- [[神经网络（Neural Network）|ANN（人工神经网络）]] 是一个宽泛的模型家族；
- ANN 可以很浅，也可以很深，因此“神经网络”与“深度学习”并非完全同义；
- CNN、RNN、Transformer 都是神经网络架构；当它们包含多层表示学习时，通常归入深度学习；
- 深度学习仍然可以采用监督、无监督、自监督或强化学习，二者不是互斥的分类方式。

### <span style="color: #1E5AA8;">1.3 机器学习与深度学习的主要区别</span>

> [!abstract] 核心结论
> **深度学习是机器学习的一个子领域**，主要使用多层神经网络自动学习特征。分类、回归、聚类是“要解决的任务”；逻辑回归、KNN、K-Means、决策树是“具体算法”；ANN、CNN、RNN、Transformer 是“神经网络家族或架构”。这些名称不处在同一个分类层级。

| 方面   | 传统机器学习                        | 深度学习                       |
| ---- | ----------------------------- | -------------------------- |
| 关系   | 机器学习中的经典方法                    | 机器学习的子领域                   |
| 典型模型 | 线性回归、决策树、随机森林、SVM、KNN、K-Means | 深层 MLP、CNN、RNN、Transformer |
| 特征获取 | 通常更依赖人工特征工程                   | 能从原始数据中逐层学习表示              |
| 数据规模 | 中小数据也常有效                      | 通常更受益于大数据；迁移学习可降低数据要求      |
| 计算需求 | 通常较低，CPU 即可完成许多任务             | 通常较高，训练常使用 GPU/专用加速器       |
| 擅长数据 | 表格数据、小样本、需解释的任务               | 图像、文本、语音、视频等非结构化数据         |
| 可解释性 | 线性模型和浅层树通常较容易解释               | 深层网络通常较难直接解释               |
| 训练时间 | 往往较短                          | 往往较长，超参数和工程因素更多            |

> [!note] 不是绝对界线
> 深度学习不一定总比传统机器学习好。对中小规模表格数据，树模型和线性模型经常是更合理的起点；对图像、文本和语音，深度学习往往更有优势。最终仍应通过验证集或交叉验证比较。

## 2. 模型
### <span style="color: #1E5AA8;">2.1按“学习范式和任务”分类</span>

#### <mark style="background:rgba(240, 107, 5, 0.2)">监督学习（Supervised Learning）</mark>

**数据形式**：每个训练样本同时具有输入 $X$ 和正确答案 $Y$。

**功能**：学习 $X\rightarrow Y$ 的映射，用于预测新样本。

##### <font color="#ff0000">A. 分类（Classification）</font>

预测离散类别，例如“是否患病”“邮件是否为垃圾邮件”“图片属于哪一类”。

已有总笔记：[[分类器]]。

代表方法：

- ✅ [[分类器#2.1 逻辑回归（Logistic Regression）|逻辑回归]]
- ✅ [[分类器#2.2 朴素贝叶斯（Naive Bayes）|朴素贝叶斯]]
- ✅ [[分类器#2.3 K 最近邻（K-Nearest Neighbors, KNN）|K 最近邻（KNN）]]
- ✅ [[分类器#2.4 决策树（Decision Tree）|决策树]]
- ✅ [[分类器#2.5 支持向量机（Support Vector Machine, SVM）|支持向量机（SVM）]]
- ✅ [[随机森林（Random Forest）|随机森林]]
- 📝 [[梯度提升树（GBDT）]]、[[XGBoost]]、[[LightGBM]]
- ✅ [[神经网络（Neural Network）|人工神经网络（ANN）]]
- 📝 [[卷积神经网络（CNN）|CNN]]：常用于图像分类
- ✅ [[RNN|循环神经网络（RNN）]]：可用于序列分类
- 📝 [[Transformer]]：常用于文本、语音和多模态分类

常见评估：准确率、Precision、Recall、F1，以及 [[混淆矩阵、ROC与AUC|混淆矩阵、ROC 与 AUC]]；将概率转为类别时还涉及[[阈值]]。

##### <font color="#ff0000">B. 回归（Regression）</font>

预测连续数值，例如房价、销售额、温度或风险分数。

代表方法：

- 📝 [[线性回归]]、[[多项式回归]]
- 📝 [[岭回归（Ridge）]]、[[Lasso 回归]]、[[Elastic Net]]
- ✅ [[分类器#2.3 K 最近邻（K-Nearest Neighbors, KNN）|KNN]]：邻居标签改为求平均即可用于回归
- ✅ [[分类器#2.4 决策树（Decision Tree）|回归树]]、随机森林回归
- 📝 [[支持向量回归（SVR）]]
- ✅ [[神经网络（Neural Network）|神经网络回归]]

常见评估：MSE、RMSE、MAE、$R^2$。

#### <mark style="background:rgba(240, 107, 5, 0.2)">无监督学习（Unsupervised Learning）</mark>

**数据形式**：只有输入 $X$，没有人工提供的正确标签 $Y$。

**功能**：发现数据的群组、低维结构、异常样本或变量之间的关系。

##### <font color="#ff0000">A. 聚类（Clustering）</font>

把相似样本放入同一个簇，常用于客户分群、文档主题探索和样本结构分析。

- ✅ [[K-Means]]：基于到聚类中心的距离划分样本
- ✅ [[层次聚类|层次聚类（Hierarchical Clustering）]]
- 📝 [[DBSCAN]]：基于密度，可识别噪声和非球状簇
- 📝 [[高斯混合模型（GMM）]]：输出样本属于各簇的概率
- 📝 [[谱聚类（Spectral Clustering）]]

##### <font color="#ff0000">B. 降维与表示学习（Dimensionality Reduction）</font>

把高维特征压缩为较少的维度，用于可视化、去噪、压缩和缓解维度灾难。

- ✅ [[主成分分析（PCA）]]；选择主成分数量时可参考[[碎石图（Scree Plot）]]
- 📝 [[t-SNE]]：主要用于高维数据可视化
- 📝 [[UMAP]]：用于非线性降维和可视化
- 📝 [[自动编码器（Autoencoder）]]：使用神经网络学习低维表示

##### <font color="#ff0000">C. 异常检测（Anomaly Detection）</font>

发现与大多数样本明显不同的观测，例如欺诈交易、设备故障和网络攻击。

- 📝 [[孤立森林（Isolation Forest）]]
- 📝 [[单类支持向量机（One-Class SVM）]]
- 📝 [[局部离群因子（LOF）]]
- 📝 [[自编码器异常检测]]

##### <font color="#ff0000">D. 关联规则（Association Rules）</font>

发现变量或商品共同出现的规律，例如“购买面包的顾客也常购买牛奶”。

- 📝 [[Apriori 算法]]
- 📝 [[FP-Growth]]

#### <mark style="background:rgba(240, 107, 5, 0.2)">半监督学习（Semi-Supervised Learning）</mark>

**数据形式**：少量有标签数据和大量无标签数据。

**功能**：在人工标注成本很高时，利用无标签样本改善分类或回归模型。

代表方法：

- 📝 [[伪标签（Pseudo-Labeling）]]
- 📝 [[一致性正则化]]
- 📝 [[标签传播（Label Propagation）]]

#### <mark style="background:rgba(240, 107, 5, 0.2)">自监督学习（Self-Supervised Learning）</mark>

**数据形式**：通常没有人工标签，训练目标由数据本身自动构造。

**功能**：先从海量数据中学习通用表示，再微调用于分类、回归或生成任务。

代表方法：

- 📝 [[掩码语言模型（Masked Language Modeling）]]
- 📝 [[对比学习（Contrastive Learning）]]
- 📝 [[自回归预训练]]

> [!tip] 自监督与无监督的关系
> 自监督通常被视为广义无监督学习的一部分，但它具有明确的、由数据自动生成的训练目标，例如遮住一句话中的词并要求模型预测该词。

#### <mark style="background:rgba(240, 107, 5, 0.2)">强化学习（Reinforcement Learning）</mark>

**数据形式**：智能体与环境交互，获得状态、动作和延迟奖励。

**功能**：学习一套策略，使长期累计奖励最大，例如游戏决策、机器人控制和资源调度。

代表方法：

- 📝 [[Q-Learning]]
- 📝 [[深度 Q 网络（DQN）]]
- 📝 [[策略梯度（Policy Gradient）]]
- 📝 [[Actor-Critic]]、[[PPO]]

### <span style="color: #1E5AA8;">2.3按“参数化与非参数化”分类</span>

- **参数化方法**：预先设定有限维形式，再估计参数，例如[[线性回归]]和[[分类器#2.1 逻辑回归（Logistic Regression）|逻辑回归]]。
- **非参数化方法**：不对未知函数设定固定的简单形式，模型复杂度可随数据变化，例如[[分类器#2.3 K 最近邻（K-Nearest Neighbors, KNN）|KNN]]和[[分类器#2.4 决策树（Decision Tree）|决策树]]。

详见：[[非参数化方法]]。

> [!warning] “非参数化”不等于“完全没有参数”
> 它主要表示模型没有预先限定为固定、有限维的函数形式，并不意味着算法中不存在 $K$、树深或带宽等超参数。

### <span style="color: #1E5AA8;">2.4模型复杂度与偏误—方差权衡</span>

模型复杂度影响模型在训练数据与新数据上的表现：

- 模型过于简单时，通常无法捕获真实规律，表现为**高偏误、低方差**，容易欠拟合；
- 模型过于复杂时，可能连训练样本中的噪声也一起学习，表现为**低偏误、高方差**，容易过拟合；
- 合理的模型需要在二者之间取得平衡，使测试误差或泛化误差尽可能低。

在平方损失条件下，预测误差可概括为：

$$
\text{期望测试误差}
=\text{偏误}^2+\text{方差}+\text{不可约误差}.
$$

随着模型灵活度提高，偏误通常下降、方差通常上升。因此，模型选择的目标不是让训练误差最低，而是利用验证集或交叉验证寻找泛化能力更好的复杂度。

- ✅ [[偏误（Bias）]]：模型长期、系统性地偏离真实规律的程度；
- ✅ [[方差（Variance）]]：训练数据发生变化时，模型预测随之波动的程度；
- ✅ [[偏误与方差权衡（Bias-Variance Trade-off）]]：二者与模型复杂度、泛化误差之间的整体关系；
- 📝 [[不可约误差（Irreducible Error）]]：数据噪声造成、模型无法完全消除的误差；
- 📝 [[欠拟合（Underfitting）]]：模型过于简单，训练集和测试集表现都较差；
- 📝 [[过拟合（Overfitting）]]：模型过度贴合训练数据，训练表现好但测试表现下降；
- 📝 [[模型复杂度（Model Complexity）]]：控制模型表达能力和灵活度的因素；
- 📝 [[交叉验证（Cross-Validation）]]：估计泛化表现并选择模型复杂度；
- 📝 [[正则化（Regularization）]]：限制模型复杂度以降低方差；
- 📝 [[学习曲线（Learning Curve）]]：利用训练集与验证集误差诊断偏误和方差。

典型关系示例：较浅的树或较大的 KNN 邻居数通常提高偏误、降低方差；较深的树或较小的 KNN 邻居数通常降低偏误、提高方差；[[随机森林（Random Forest）|随机森林]]则通过集成多棵去相关的树重点降低方差。

## 3. 神经网络架构

### <span style="color: #1E5AA8;">3.1 ANN 是上位概念</span>

**ANN（Artificial Neural Network）** 泛指由神经元、权重、偏置和非线性变换组成的人工神经网络。基础结构参见[[神经网络（Neural Network）]]。

训练神经网络通常涉及：

1. [[前向传播（Forward Propagation）]]：从输入计算到预测；
2. [[激活函数]]：为网络引入非线性；
3. [[损失函数]]：衡量预测与真实答案的差异；
4. [[反向传播（Backpropagation）]]：根据链式法则计算梯度；
5. [[优化算法]]：使用梯度下降、Adam 等更新权重；
6. 监控[[梯度消失]]、梯度爆炸和过拟合。

其中，[[Sigmoid 函数]] 是常见输出或门控激活函数。

### <span style="color: #1E5AA8;">3.2 常见神经网络架构</span>

| 架构 | 主要功能 | 擅长的数据 | 代表应用 |
|---|---|---|---|
| 📝 [[多层感知机（MLP）]] | 通用非线性映射 | 固定长度向量、表格特征 | 分类、回归 |
| 📝 [[卷积神经网络（CNN）]] | 用局部卷积提取空间特征 | 图像、网格、局部时序信号 | 图像分类、目标检测、分割 |
| ✅ [[RNN\|循环神经网络（RNN）]] | 通过循环状态处理顺序信息 | 文本、语音、时间序列 | 序列分类、序列预测 |
| ✅ [[RNN#6.1 LSTM：长短时记忆网络\|LSTM]] | 用门控记忆缓解长期依赖问题 | 较长序列 | 时间序列、文本、语音 |
| ✅ [[RNN#6.2 GRU：门控循环单元\|GRU]] | 用更简化的门控结构处理序列 | 序列数据 | 分类、预测、生成 |
| 📝 [[Transformer]] | 用注意力直接建模远距离关系 | 文本、图像、语音、多模态 | 大语言模型、视觉模型 |
| 📝 [[图神经网络（GNN）]] | 聚合邻居节点信息 | 图结构数据 | 社交网络、分子、推荐 |
| 📝 [[自动编码器（Autoencoder）]] | 压缩并重建输入 | 无标签高维数据 | 降维、去噪、异常检测 |
| 📝 [[生成对抗网络（GAN）]] | 生成器与判别器对抗训练 | 图像等复杂分布 | 数据生成、图像转换 |
| 📝 [[扩散模型（Diffusion Model）]] | 学习逐步去噪生成数据 | 图像、音频、视频 | 内容生成 |

> [!note] CNN 为什么属于深度学习
> CNN 本质上仍是 ANN，只是把普通全连接替换或结合为卷积、池化等结构，特别适合捕获局部空间模式，例如图像边缘、纹理和形状。参见现有笔记：[[数捕获图像边缘和线条的非线性特征]]。


### <span style="color: #1E5AA8;">3.3 ANN、KNN、CNN、RNN、K-Means 快速辨析</span>

| 名称                                               | 属于什么      |   是否通常需要标签 | 主要功能            |
| ------------------------------------------------ | --------- | ---------: | --------------- |
| [[神经网络（Neural Network）\|ANN]]                    | 神经网络总称    |    取决于训练范式 | 通用分类、回归、表示学习与生成 |
| [[卷积神经网络（CNN）\|CNN]]                             | ANN 的卷积架构 | 通常需要；也可自监督 | 提取图像等数据的局部空间特征  |
| [[RNN]]                                          | ANN 的循环架构 |      取决于任务 | 处理序列和时间依赖       |
| [[分类器#2.3 K 最近邻（K-Nearest Neighbors, KNN）\|KNN]] | 基于邻居的算法   |          是 | 分类或回归           |
| [[K-Means]]                                      | 基于距离的聚类算法 |          否 | 将样本划分为 $K$ 个簇   |

最重要的区别：

- KNN 与 K-Means 名称中都有 $K$，但 KNN 的 $K$ 是**邻居数**，K-Means 的 $K$ 是**簇数**；
- CNN 和 RNN 是神经网络“怎么连接”的架构，不是只对应一个任务；
- 同一个 CNN 可用于分类、回归或特征提取，同一个 RNN 可用于分类、预测或生成。

## 4. 数据处理与辅助方法

> [!abstract] 本章定位
> 把原始数据转化为适合建模的输入，解决数据质量、数据划分、量纲差异、类别不平衡、维度过高和数据泄漏等问题。具体处理步骤位于“原始数据”和“模型训练”之间，数据管道则负责保证这些步骤在训练、验证、测试和部署阶段保持一致。

![[数据预处理工作流.canvas]]

*图：主流程按照第五章小节顺序排列；降维可以进入模型训练，也可以作为数据可视化的入口。5.7 数据管道贯穿整个流程，并不只是最后执行的一步。*

### <span style="color: #1E5AA8;">4.1 数据清洗与转换</span>

**功能**：修正原始数据中的质量问题，确保每行样本、每列变量和数据类型都符合分析要求。

- 📝 [[数据预处理（Data Preprocessing）]]：从原始数据到可建模数据的完整流程；
- 📝 [[缺失值处理]]：删除、简单填补或基于模型进行插补；
- 📝 [[重复值处理]]：识别并处理重复记录；
- 📝 [[异常值处理]]：识别极端观测，并判断其是错误、特殊案例还是合理值；
- 📝 [[数据类型转换]]：正确区分数值、类别、日期和文本变量；
- 📝 [[变量变换]]：对数、平方根、Box-Cox 等变换；
- 📝 [[数据质量检查]]：检查取值范围、单位、编码和逻辑一致性。

> [!warning] 异常值不等于错误值
> 不应仅因一个观测“看起来极端”就删除它。应结合数据来源和业务背景判断，并比较保留、变换、稳健建模等不同处理方案。

### <span style="color: #1E5AA8;">4.2 数据划分与泄漏预防</span>

**功能**：在拟合任何预处理规则或模型之前划分数据，明确训练、调参与最终评估所使用的数据范围。

- ✅ [[训练集、验证集与测试集]]：训练集用于拟合，验证集用于选择方案和[[超参数]]，测试集用于最终独立评估；
- 📝 [[数据泄漏（Data Leakage）]]：训练过程中错误使用了未来数据、测试集或目标信息；
- 📝 [[分层抽样（Stratified Sampling）]]：使不同数据子集保持近似的类别比例；
- 📝 [[时间序列数据划分]]：保持时间顺序，避免把未来信息用于预测过去。

> [!important] 先划分，再拟合
> 任何会“从数据中学习参数”的预处理步骤，例如均值、标准差、缺失值填充值、类别编码规则、PCA 载荷和特征选择，都只能在训练集上拟合，再原样应用于验证集、测试集和未来数据。若先使用全体数据计算这些信息，就会造成数据泄漏。

### <span style="color: #1E5AA8;">4.3 特征缩放与类别编码</span>

**功能**：把不同量纲和数据类型转换为算法能够合理比较和计算的数值表示。

#### 数值特征缩放

- 📝 [[数据标准化（Standardization）]]：转换为均值约为 0、标准差约为 1；
- 📝 [[数据归一化（Normalization）]]：通常缩放到 $[0,1]$ 等固定区间；
- 📝 [[稳健缩放（Robust Scaling）]]：使用中位数和四分位距，降低异常值影响。

对距离或梯度敏感的方法通常需要缩放，例如：
- [[分类器#2.3 K 最近邻（K-Nearest Neighbors, KNN）|KNN]]；[[K-Means]]；[[分类器#2.5 支持向量机（Support Vector Machine, SVM）|SVM]]；逻辑回归的正则化版本和神经网络。
- 决策树和[[随机森林（Random Forest）|随机森林]]通常对单调缩放不敏感，一般不必仅为模型本身进行标准化。

#### 类别特征编码

- 📝 [[类别变量编码]]；
- 📝 [[独热编码（One-Hot Encoding）]]：适合无序类别；
- 📝 [[有序类别编码（Ordinal Encoding）]]：适合具有真实顺序的类别；
- 📝 [[目标编码（Target Encoding）]]：使用目标变量信息编码，必须严格防止数据泄漏；
- 📝 [[文本向量化]]：词袋、TF-IDF、词嵌入等。

### <span style="color: #1E5AA8;">4.4 特征工程与特征选择</span>

**功能**：构造更有信息量的变量，并去除无关、冗余或不稳定的变量。

#### 特征工程

- 📝 [[特征工程（Feature Engineering）]]；
- 📝 [[交互项]]：表示两个变量共同作用；
- 📝 [[多项式特征]]：表达非线性关系；
- 📝 [[时间特征工程]]：从日期提取星期、月份、间隔和周期；
- 📝 [[分组与聚合特征]]：例如客户历史平均消费和购买频率；
- 📝 [[领域知识特征]]：根据研究问题构造有实际含义的指标。

#### 特征选择

- 📝 [[特征选择（Feature Selection）]]；
- 📝 [[过滤法（Filter Method）]]：先根据相关性、统计检验等筛选；
- 📝 [[包裹法（Wrapper Method）]]：通过反复训练模型比较特征子集；
- 📝 [[嵌入法（Embedded Method）]]：在模型训练过程中完成选择，如 Lasso 和树模型；
- 📝 [[递归特征消除（RFE）]]；
- 📝 [[多重共线性]]与[[方差膨胀因子（VIF）]]。

> [!note] 特征选择与降维的区别
> 特征选择保留原始变量中的一部分；降维通常把多个原始变量组合成新的低维表示。前者通常更容易解释，后者可能保留更多整体信息。

### <span style="color: #1E5AA8;">4.5 降维与数据可视化</span>

**功能**：减少特征数量、压缩信息、降低噪声，并帮助观察高维数据结构。

#### 用于压缩或建模的降维

- ✅ [[主成分分析（PCA）]]：寻找解释数据方差最多的正交线性组合；
- ✅ [[碎石图（Scree Plot）]]：辅助判断 PCA 应保留多少个主成分；
- 📝 [[自动编码器（Autoencoder）]]：使用神经网络学习低维表示；
- 📝 [[特征哈希（Feature Hashing）]]：压缩高维稀疏特征。

#### 主要用于观察结构的可视化

- 📝 [[t-SNE]]：强调局部邻域结构，主要用于二维或三维可视化；
- 📝 [[UMAP]]：用于非线性降维和可视化。

PCA 既是一种无监督学习方法，也可作为监督模型之前的辅助步骤；同一方法可以在不同章节出现，但应链接到同一份主笔记。

> [!warning] 可视化距离不一定等于真实距离
> t-SNE、UMAP 等二维图会改变高维空间中的部分距离关系，不能只凭图上簇的分离程度证明真实数据存在明确类别，也不应直接把可视化效果当作聚类性能。

### <span style="color: #1E5AA8;">4.6 样本重采样、数据增强与类别不平衡</span>

**功能**：只对训练数据改变样本构成或生成合理变体，以估计不确定性、扩充数据或缓解少数类别样本过少的问题。

- ✅ [[集成学习#3. Bootstrap：为模型制造不同训练集|Bootstrap 重采样]]：有放回抽样，可用于误差估计和 Bagging；
- 📝 [[上采样（Oversampling）]]：增加少数类样本；
- 📝 [[下采样（Undersampling）]]：减少多数类样本；
- 📝 [[SMOTE]]：在特征空间中合成少数类样本；
- 📝 [[类别权重（Class Weight）]]：提高少数类错误在损失函数中的代价；
- 📝 [[数据增强（Data Augmentation）]]：在图像、文本、语音等任务中产生合理的训练样本变体。

> [!warning] 样本处理的适用范围
> 应先划分训练集和测试集，再只对训练集执行上采样、下采样、SMOTE 或数据增强。若先对全体数据合成样本，相似或重复信息可能同时进入训练集和测试集，造成过于乐观的评估结果。

### <span style="color: #1E5AA8;">4.7 数据管道、可重复性与部署一致性</span>

**功能**：把 4.1～4.6 的处理步骤组织为可重复执行的整体，保证训练、验证、测试和部署阶段采用一致的数据处理规则。

- 📝 [[机器学习管道（Pipeline）]]：把填补、缩放、编码、特征选择、降维、样本处理和模型串成可重复流程；
- 📝 [[可重复性（Reproducibility）]]：固定随机种子，并记录数据版本、代码版本和参数；
- 📝 [[训练—服务偏差（Training-Serving Skew）]]：训练和部署时的特征计算规则不一致。

> [!note] 4.7 不是最后才执行的一步
> 数据管道是包裹前述步骤的执行框架。训练时在训练集上调用“拟合并转换”，验证集、测试集和未来数据只能调用“转换”；部署时还要复用同一套预处理对象和特征计算规则。

### <span style="color: #1E5AA8;">9.2 线性代数：描述数据与模型</span>

#### A. 标量、向量、矩阵和张量

- **标量（scalar）**：单个数，例如学习率 $\eta=0.01$；
- **向量（vector）**：一列有顺序的数，例如一个样本的 $p$ 个特征；
- **矩阵（matrix）**：二维数表，例如包含 $n$ 个样本、$p$ 个特征的数据矩阵 $X\in\mathbb{R}^{n\times p}$；
- **张量（tensor）**：更高维数组，例如一批彩色图像可表示为“样本数 × 高度 × 宽度 × 通道数”。

矩阵维度必须匹配才能相乘。例如：

$$
X_{n\times p}\boldsymbol\beta_{p\times1}
=\hat{\boldsymbol y}_{n\times1}.
$$

这就是线性回归和逻辑回归常见的矩阵表达。

#### B. 内积、范数和距离

两个向量的内积为：

$$
\boldsymbol x^T\boldsymbol y
=\sum_{j=1}^{p}x_jy_j.
$$

它可以用于描述方向关系。欧氏范数为：

$$
\|\boldsymbol x\|_2
=\sqrt{\sum_{j=1}^{p}x_j^2},
$$

欧氏距离则是：

$$
d(\boldsymbol x,\boldsymbol y)
=\|\boldsymbol x-\boldsymbol y\|_2.
$$

对应关系：

- [[分类器#2.3 K 最近邻（K-Nearest Neighbors, KNN）|KNN]] 根据距离寻找邻居；
- [[K-Means]] 根据距离分配样本并更新聚类中心；
- [[层次聚类]] 先计算样本距离，再通过联动方式定义簇间距离；
- SVM 使用内积、范数和几何间隔构造分类边界。

#### C. 正交与投影

若两个向量满足

$$
\boldsymbol u^T\boldsymbol v=0,
$$

则它们[[彼此正交]]。向量 $\boldsymbol x$ 在单位方向 $\boldsymbol v$ 上的投影长度为：

$$
z=\boldsymbol x^T\boldsymbol v.
$$

在 [[主成分分析（PCA）]] 中：

- 主成分方向彼此正交；
- 主成分得分就是样本在新方向上的投影坐标；
- PCA 通过投影把高维数据表示到较少的主成分轴上。

#### D. 逆矩阵、秩与线性相关

- **逆矩阵**可以理解为矩阵变换的“反操作”，但并非所有矩阵都可逆；
- **秩（rank）**表示矩阵中独立信息方向的数量；
- 若某些特征可以由其他特征线性组合得到，设计矩阵可能不满秩，并产生[[多重共线性]]问题；
- 岭回归通过 $L_2$ 正则化改善强共线性下参数估计的不稳定性。

普通最小二乘的经典解写作：

$$
\hat{\boldsymbol\beta}
=(X^TX)^{-1}X^T\boldsymbol y,
$$

但实际计算通常不会直接求逆，而会采用 QR 分解、SVD 等更稳定的方法。

#### E. 特征值、特征向量与 SVD

若

$$
A\boldsymbol v=\lambda\boldsymbol v,
$$

则 $\boldsymbol v$ 是矩阵 $A$ 的特征向量，$\lambda$ 是对应特征值。它表示矩阵变换后方向不变，只发生长度缩放的特殊方向。

在 PCA 中：

- 对协方差矩阵做特征值分解；
- 特征向量给出主成分方向；
- 特征值给出对应主成分解释的方差；
- SVD 是实际计算 PCA 时常用且数值更稳定的方法。

### <span style="color: #1E5AA8;">9.3 微积分：理解模型如何学习</span>

#### A. 导数与斜率

导数描述函数输出对输入的瞬时变化率：

$$
f'(x)=\lim_{h\to0}\frac{f(x+h)-f(x)}{h}.
$$

在机器学习中，导数主要用于回答：**参数改变一点，损失函数会怎样变化？**

#### B. 偏导数与梯度

模型通常有很多参数。损失函数 $L(\theta_1,\ldots,\theta_m)$ 对所有参数的偏导数组成梯度：

$$
\nabla L(\boldsymbol\theta)
=\begin{bmatrix}
\frac{\partial L}{\partial\theta_1}\\
\vdots\\
\frac{\partial L}{\partial\theta_m}
\end{bmatrix}.
$$

梯度指向函数上升最快的方向，因此梯度下降沿相反方向更新参数：

$$
\boldsymbol\theta^{(t+1)}
=\boldsymbol\theta^{(t)}-\eta\nabla L(\boldsymbol\theta^{(t)}).
$$

其中 $\eta$ 是学习率。

#### C. 链式法则

复合函数的导数需要逐层相乘：

$$
\frac{dL}{dx}
=\frac{dL}{dz}\frac{dz}{dx}.
$$

链式法则是 [[反向传播（Backpropagation）]] 的数学核心。神经网络先通过[[前向传播（Forward Propagation）]]计算预测和损失，再从输出层向输入层逐层传播梯度。

#### D. 二阶导数与曲率

- 一元函数的二阶导数描述曲线弯曲程度；
- 多元函数的二阶偏导数组成 Hessian 矩阵；
- 二阶信息可用于判断极值和设计牛顿法等优化算法；
- 入门阶段先熟练掌握一阶梯度即可，Hessian 属于进阶内容。

对应模型：

| 微积分知识 | 对应方法 | 作用 |
|---|---|---|
| 一阶导数 | 线性回归、逻辑回归 | 求损失函数的下降方向 |
| 偏导数与梯度 | SVM、神经网络 | 同时更新多个模型参数 |
| 链式法则 | MLP、CNN、RNN、Transformer | 完成反向传播 |
| 二阶导数 | 牛顿法、部分统计模型 | 利用曲率加速或分析优化 |
| 函数极值 | PCA、K-Means、模型训练 | 理解“最大化方差”或“最小化损失” |

### <span style="color: #1E5AA8;">9.4 概率统计：描述数据与不确定性</span>

#### A. 随机变量与概率分布

需要理解：

- 离散变量与连续变量；
- 概率质量函数、概率密度函数和累积分布函数；
- 伯努利分布、二项分布、正态分布和多元正态分布；
- 从总体、样本和抽样分布三个层面区分不确定性。

典型对应：

- 逻辑回归常把二分类结果看作伯努利变量；
- 朴素贝叶斯根据特征类型选择不同条件分布；
- 高斯混合模型使用多个正态分布描述潜在簇；
- 回归模型经常假设误差具有零均值、恒定方差或近似正态等性质。

#### B. 期望、方差、协方差与相关性

期望描述随机变量的平均水平：

$$
E[X]=\sum_x xP(X=x)
\quad\text{或}\quad
E[X]=\int x f(x)\,dx.
$$

方差描述变量围绕均值的波动：

$$
\operatorname{Var}(X)
=E[(X-E[X])^2].
$$

协方差描述两个变量共同变化的方向：

$$
\operatorname{Cov}(X,Y)
=E[(X-E[X])(Y-E[Y])].
$$

这些概念对应：

- PCA 从协方差矩阵中寻找方差最大的方向；
- [[碎石图（Scree Plot）]]展示各主成分解释的方差；
- [[偏误与方差权衡（Bias-Variance Trade-off）]]使用“方差”描述模型对训练数据变化的敏感程度；
- 相关性、协方差与多重共线性分析用于理解变量之间的线性关系。

> [!warning] 三种“方差”要区分
> 原始变量的方差、PCA 的解释方差、偏误—方差分解中的模型方差相互相关但含义不同，不能混用。

#### C. 条件概率与贝叶斯公式

条件概率表示在已知 $B$ 的情况下 $A$ 发生的概率：

$$
P(A\mid B)=\frac{P(A\cap B)}{P(B)}.
$$

贝叶斯公式为：

$$
P(Y\mid X)
=\frac{P(X\mid Y)P(Y)}{P(X)}.
$$

[[分类器#2.2 朴素贝叶斯（Naive Bayes）|朴素贝叶斯]]利用该公式把先验概率和特征条件概率组合为类别后验概率。

#### D. 似然、对数似然与参数估计

概率回答“参数已知时，数据出现的可能性”；似然把已经观察到的数据固定下来，比较哪些参数更能解释数据：

$$
L(\boldsymbol\theta)
=P(\text{data}\mid\boldsymbol\theta).
$$

多个样本的概率乘积容易数值下溢，因此通常使用对数似然：

$$
\ell(\boldsymbol\theta)
=\log L(\boldsymbol\theta).
$$

最大似然估计（MLE）选择使似然最大的参数。逻辑回归、朴素贝叶斯、GMM 和许多神经网络损失都可以从最大似然角度理解。

#### E. 抽样、估计与评估

- 训练集、验证集和测试集是从有限数据估计泛化能力的基本框架；
- [[集成学习#3. Bootstrap：为模型制造不同训练集|Bootstrap]]通过有放回抽样构造不同训练集；
- 交叉验证用于估计模型在新数据上的平均表现；
- 置信区间和假设检验用于表达估计的不确定性，但不能只依赖 $p$ 值判断实际意义。

### <span style="color: #1E5AA8;">9.5 最优化：把学习问题写成目标函数</span>

模型训练通常可以写成：

$$
\min_{\boldsymbol\theta}
\left[
\text{数据损失}(\boldsymbol\theta)
+\lambda\,\text{复杂度惩罚}(\boldsymbol\theta)
\right].
$$

需要掌握以下概念：

- **目标函数/损失函数**：模型要最小化或最大化的量；
- **全局最优与局部最优**：整体最好与局部邻域最好；
- **凸函数**：局部最优也是全局最优，通常更容易优化；
- **约束优化**：参数必须满足某些条件；
- **梯度下降与随机梯度下降**：沿梯度反方向迭代更新；
- **学习率**：控制每次更新步长；
- **正则化**：在拟合数据之外惩罚模型复杂度。

#### 不同模型的优化目标

| 模型或方法 | 主要目标 |
|---|---|
| 线性回归 | 最小化残差平方和 |
| 逻辑回归 | 最小化对数损失，等价于最大化对数似然 |
| 岭回归 | 残差平方和加 $L_2$ 惩罚 |
| Lasso | 残差平方和加 $L_1$ 惩罚 |
| SVM | 在分类错误惩罚与最大间隔之间权衡 |
| [[K-Means]] | 最小化簇内平方和 |
| [[主成分分析（PCA）]] | 最大化投影方差，或最小化低秩重构误差 |
| 神经网络 | 通过梯度类算法最小化任务损失 |
| Boosting / XGBoost | 逐步添加弱学习器以降低损失 |

> [!note] 并非所有算法都用普通梯度下降
> 决策树通过贪心切分变量，K-Means 交替执行样本分配和中心更新，随机森林训练多棵随机化决策树。它们同样在优化某种准则，但计算方式与神经网络不同。

### <span style="color: #1E5AA8;">9.6 几何、距离与决策边界</span>

#### 常见距离与相似度

| 名称 | 形式或直观含义 | 常见用途 |
|---|---|---|
| 欧氏距离 | 空间中两点的直线距离 | KNN、K-Means、层次聚类 |
| 曼哈顿距离 | 各维绝对差之和 | 稀疏数据、对极端差异较稳健的距离比较 |
| 余弦相似度 | 比较向量夹角，而非绝对长度 | 文本向量、嵌入表示、推荐系统 |
| 闵可夫斯基距离 | 欧氏距离与曼哈顿距离的推广 | KNN 等距离模型 |
| 马氏距离 | 考虑变量尺度和相关结构 | 多变量异常检测、椭圆形分布 |

#### 超平面与间隔

线性分类边界可以写成：

$$
\boldsymbol w^T\boldsymbol x+b=0.
$$

- 二维空间中它是一条直线；
- 三维空间中它是一个平面；
- 更高维中称为超平面；
- SVM 寻找能够分隔类别且间隔尽可能大的超平面；
- 核方法通过内积函数隐式表示更高维的特征空间。

> [!important] 特征缩放与几何
> KNN、K-Means、层次聚类和 SVM 都会受到距离、内积或间隔的影响，因此通常需要检查特征尺度。树模型按阈值切分，对单调缩放通常不敏感。

### <span style="color: #1E5AA8;">9.7 信息论：分类与表示学习的损失</span>

#### A. 熵

熵衡量概率分布的不确定性：

$$
H(Y)=-\sum_{k}p_k\log p_k.
$$

- 类别越混杂，熵通常越大；
- 决策树可以选择使熵下降最多，即信息增益最大的切分。

#### B. 交叉熵

分类任务常用交叉熵衡量真实分布与预测概率的差异：

$$
H(p,q)=-\sum_k p_k\log q_k.
$$

它对应逻辑回归和神经网络分类中的对数损失。模型如果给真实类别很低的预测概率，会受到较大惩罚。

#### C. KL 散度

KL 散度衡量一个概率分布相对于另一个分布的信息差异：

$$
D_{\mathrm{KL}}(P\|Q)
=\sum_x P(x)\log\frac{P(x)}{Q(x)}.
$$

它不是对称距离，常见于变分推断、生成模型、知识蒸馏和分布匹配。

### <span style="color: #1E5AA8;">9.8 数值计算与工程基础</span>

数学公式正确，并不保证计算机直接计算时稳定。还需要理解：

- **标准化**：避免特征尺度差异主导距离或梯度；
- **数值下溢与上溢**：很小概率连乘或指数函数可能超出浮点数范围；
- **对数变换**：把概率乘积变成对数之和，提高稳定性；
- **矩阵病态与条件数**：特征强相关时，小扰动可能造成参数大幅变化；
- **迭代停止条件**：损失变化、梯度大小或迭代次数达到阈值；
- **随机种子**：控制数据划分、初始化和重采样，使实验可重复；
- **时间与空间复杂度**：例如层次聚类的距离矩阵需要 $O(n^2)$ 存储；
- **向量化计算**：使用矩阵运算代替大量显式循环，提高 R、Python 和加速器上的效率。

典型例子：

- `log(1 + exp(x))` 在 $x$ 很大时可能溢出，需要稳定实现；
- 计算最小二乘时，直接求 $(X^TX)^{-1}$ 往往不如 QR 或 SVD 稳定；
- 神经网络中的梯度消失和梯度爆炸同时涉及微积分、矩阵连乘和数值尺度。

### <span style="color: #1E5AA8;">9.9 前文模型—数学基础对照表</span>

| 模型或方法 | 最需要的数学基础 | 对应关系 |
|---|---|---|
| 线性回归 | 矩阵、导数、期望、方差、最小二乘 | 用 $X\boldsymbol\beta$ 表示预测，通过平方损失估计参数 |
| 逻辑回归 | Sigmoid、条件概率、对数似然、梯度 | 将线性输出转为概率，通过交叉熵训练 |
| 朴素贝叶斯 | 条件概率、贝叶斯公式、概率分布 | 组合先验概率和类条件概率进行分类 |
| KNN | 向量、距离、尺度、投票或平均 | 根据最近邻样本完成分类或回归 |
| 决策树 | 条件概率、熵、基尼指数、贪心优化 | 选择能提高节点纯度的切分 |
| 随机森林 | Bootstrap、随机变量、方差、集成平均 | 组合去相关树，重点降低模型方差 |
| Boosting / XGBoost | 损失函数、梯度、正则化、加法模型 | 逐步修正已有模型的错误 |
| SVM | 向量内积、范数、超平面、约束优化、核函数 | 最大化分类间隔并允许一定误差 |
| K-Means | 欧氏距离、均值、簇内平方和、交替优化 | 反复分配样本并更新中心 |
| 层次聚类 | 距离矩阵、联动规则、树结构 | 根据簇间差异逐层合并样本 |
| PCA | 中心化、协方差矩阵、正交投影、特征值、SVD | 寻找解释方差最大的正交方向 |
| GMM | 多元正态分布、条件概率、似然、EM 算法 | 用多个概率分布软性表示不同簇 |
| MLP / ANN | 矩阵乘法、偏导数、链式法则、优化 | 前向计算预测，反向传播梯度 |
| CNN | 张量、卷积、局部连接、梯度 | 在网格数据上提取局部空间模式 |
| RNN / LSTM / GRU | 矩阵、序列递推、链式法则、概率 | 通过循环状态表示时间依赖 |
| Transformer | 矩阵、点积、Softmax、概率、复杂度 | 使用查询、键和值计算注意力 |
| 自动编码器 | 矩阵、非线性函数、重构误差、梯度 | 压缩输入并学习重建 |
| 异常检测 | 概率尾部、距离、密度、分位数 | 判断样本是否偏离主要数据结构 |
| 强化学习 | 条件概率、期望、马尔可夫过程、动态规划 | 最大化长期累计奖励 |

### <span style="color: #1E5AA8;">9.10 建议学习顺序</span>

#### 第一阶段：能够读懂经典模型

1. 函数、指数、对数和求和符号；
2. 向量、矩阵、转置与矩阵乘法；
3. 均值、方差、协方差和相关系数；
4. 欧氏距离、内积、范数和投影；
5. 导数、偏导数、梯度和链式法则；
6. 基本概率、条件概率和常见分布。

#### 第二阶段：理解模型为什么这样训练

1. 似然、对数似然和最大似然估计；
2. 损失函数、梯度下降和学习率；
3. $L_1$、$L_2$ 正则化；
4. 特征值、特征向量、矩阵秩和 SVD；
5. 凸优化、约束优化和局部最优；
6. 熵、交叉熵和信息增益。

#### 第三阶段：按模型深入

- 学 PCA：重点补协方差矩阵、正交投影、特征值与 SVD；
- 学 SVM：重点补向量几何、拉格朗日乘子和核方法；
- 学神经网络：重点补多元微积分、链式法则、矩阵求导与数值稳定性；
- 学概率模型：重点补概率分布、最大似然、贝叶斯推断和 EM 算法；
- 学 Transformer：重点补矩阵运算、点积注意力、Softmax 和计算复杂度；
- 学强化学习：重点补条件期望、马尔可夫链和动态规划。

> [!summary] 最低必备数学框架
> **用矩阵表示数据，用概率描述不确定性，用损失函数定义目标，用导数和优化算法学习参数，用几何和距离理解样本关系。** PCA 中的矩阵只是这个框架的一部分。
