# Machine-Learning-Notes
个人机器学习的开源笔记，可以自行下载后编辑，感谢关注与订阅！Personal study notes on machine learning methods and their mathematical foundations, organized with Obsidian Canvas and Markdown.
网页版笔记在：https://61792.github.io/Machine-Learning-Notes/

（后面还会继续更新：机器学习方法总览、各项方法模型等笔记链接。如果收到足够多的关注会更有动力更新的；）

该笔记的正确使用方式：通过obsidian阅读，下载claudian插件辅助编辑（非必须），advance canvas辅助阅读（必须）。学习是一个非线性的过程，需要不断的更新迭代，如有错误欢迎各位温和指正。
